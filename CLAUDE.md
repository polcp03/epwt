# ePWT — Electric Powertrain Platform

Proyecto de aprendizaje desde cero de electrónica de potencia y powertrain eléctrico: miniquad eléctrico, inversor, motor, y MCU/firmware propios (no de terceros).

## Enfoque: AI-first, harness propio

No se usa un SDK/framework de agentes de terceros tal cual. El objetivo incluye **construir un harness de agentes propio** (loop de acción, herramientas, modelo de permisos) como parte del proyecto, no solo consumirlo.
