# Experiments

Un archivo Markdown por experimento: `EXP-001-nombre-corto.md`.

Plantilla:

```markdown
# EXP-001: Título

- **Objetivo:** qué se quiere averiguar
- **Hipótesis:** qué se espera que pase
- **Setup/parámetros:** condiciones del experimento
- **Cambios respecto al baseline:** qué se modificó
- **Resultados:** qué se obtuvo (datos, gráficas, logs)
- **Conclusión:** confirma o refuta la hipótesis
- **Limitaciones:** qué no cubre este experimento
- **Próximas acciones:** qué sigue
```
