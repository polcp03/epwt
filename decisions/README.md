# Engineering Decisions

Un archivo Markdown por decisión: `DEC-001-nombre-corto.md`.

Plantilla:

```markdown
# DEC-001: Título

- **Decisión:** qué se decidió
- **Alternativas consideradas:** qué otras opciones había
- **Razonamiento:** por qué se eligió esta
- **Asunciones:** qué se está dando por hecho
- **Consecuencias:** qué implica esta decisión
- **Evidencia:** datos/tests/referencias que la respaldan
- **Fecha:**
```

Registrar aquí decisiones con impacto real (arquitectura, elección de hardware/software, trade-offs), no cualquier detalle menor.
