# Requirements

Un archivo Markdown por requirement: `REQ-001-nombre-corto.md`.

Plantilla:

```markdown
# REQ-001: Título

- **Descripción:** qué debe cumplir el sistema
- **Justificación:** por qué existe este requirement
- **Fuente:** de dónde viene (mentor, decisión propia, norma...)
- **Prioridad:** alta / media / baja
- **Estado:** propuesto / aceptado / implementado / verificado
- **Verificación:** cómo se comprueba (test, simulación, medida)
```
