# ePWT — Electric Powertrain Platform

Proyecto de aprendizaje desde cero de electrónica de potencia y powertrain eléctrico (miniquad eléctrico, inversor, motor, MCU/firmware propios), desarrollado como organización de ingeniería AI-first con Claude Code.

Ver [CLAUDE.md](CLAUDE.md) para el contexto de trabajo con el agente, y [docs/context](docs/context/) para la arquitectura completa del harness.

## Estructura

- [`requirements/`](requirements/) — qué debe hacer el sistema y por qué
- [`tasks/`](tasks/) — trabajo pendiente/en curso, ligado a requirements
- [`experiments/`](experiments/) — hipótesis, pruebas, resultados
- [`decisions/`](decisions/) — decisiones de ingeniería y sus alternativas descartadas
- [`docs/`](docs/) — documentación técnica y reportes semanales

Todo el conocimiento estructurado del proyecto vive aquí, versionado en Git — no hay ninguna herramienta externa (Notion, etc.) como fuente de verdad todavía.
